# PLAN.md — план разработки

Общий план разработки. Этапы идут по порядку: каждый следующий опирается на предыдущий.

## Как работать с Claude по этому плану

- Один этап — одна или несколько сессий. Начинай сессию так: *«Прочитай CLAUDE.md и PLAN.md. Делаем этап N, задачу N.M»*.
- Задачи внутри этапа давай по одной, а не весь этап сразу.
- После каждой задачи: тесты проходят → коммит → отметка `[x]` в этом файле.
- Если по ходу появилось решение, которое стоит обосновать в ПЗ, попроси Claude записать ADR в `docs/adr/`.
- Если что-то пошло не по плану, сначала обнови этот файл, потом продолжай.

## Что запросить заранее (не код, но блокирует этапы)

| Что | У кого | Нужно к этапу |
|---|---|---|
| Методичка / требования к оформлению ВКР кафедры | Руководитель | 4 (форматирование) |
| 3–5 реальных ВКР прошлых лет в .docx (можно обезличенные) | Руководитель / кафедра | 4 (тестовые данные) |

## Если не успеваю — что можно урезать

В порядке «урезать в первую очередь»:
1. Уведомления (этап 7) — оставить только подсветку просрочек в интерфейсе
2. Сравнение версий (3.4) — оставить только историю
3. Редактирование шаблона этапов из UI (2.7) — оставить seed
4. Список литературы (4.8) — оставить только проверку без автоисправления

Форматирование, этапы, версии и антиплагиат не урезаются: это основа темы.

## Отложенные решения

### LibreOffice headless — нужен или нет
Сервер не может использовать сам Word, а python-docx не умеет раскладывать текст по страницам. Варианты:
- **Содержание:** вместо LibreOffice выставлять в .docx флаг `updateFields`. Word сам обновит оглавление и номера страниц, когда студент откроет файл.
- **Подсчёт страниц (требование ≥ 40 стр.):** без LibreOffice невозможен. Число страниц в свойствах файла устаревает после правок системы. LibreOffice может расходиться с Word на 1–2 страницы; если поставить в контейнер шрифты Microsoft, расхождение минимальное.
- **Предпросмотр в браузере (PDF):** без LibreOffice его не будет, только скачивание.

Предварительно: содержание через `updateFields`, LibreOffice только для подсчёта страниц и предпросмотра. Решить до этапа 4 (задача 4.7).
