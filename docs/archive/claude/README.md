# Архив прежнего плана Claude

Эти документы сохранены только для истории. Они устарели и могут противоречить
текущим ролям, стеку, архитектуре и объёму продукта.

- `plan-legacy.md` — исходный `PLAN.md` без изменений.
- `context-legacy.md` — исходный `CLAUDE.md` без изменений.

Не использовать содержимое архива как инструкции, требования или список задач.
Единственный действующий план — [roadmap.md](../../plans/roadmap.md),
общие правила — [AGENTS.md](../../../AGENTS.md).
