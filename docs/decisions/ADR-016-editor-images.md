# ADR-016 — Загрузка изображений из редактора

**Статус:** принято для серверной части ED-04/05.

При вставке изображения редактор загружает PNG или JPEG отдельным запросом.
Сервер сверяет заголовок `Content-Type` с форматом файла и использует тот же
декодер, что и импорт DOCX. Хранится перекодированный PNG без исходных
метаданных. Лимиты загрузки и результата — 10 МиБ, размера — 20 млн пикселей.

Изображение используют через существующий `DocumentAsset` и `norma-image`.
Для прямой загрузки `import_id` пустой. Миграция `0012_editor_image_upload`
сохраняет существующие assets и блокирует откат при наличии прямых загрузок.
Запись остаётся доступной истории версий после восстановления документа.

Только студент-владелец может загрузить файл при наличии аренды и актуальной
ревизии. После декодирования обе проверки повторяются под блокировкой документа.
Загрузка создаёт asset без изменения JSON или ревизии. Привязка к тексту проходит
через сохранение документа с обычными правилами владения и проверки глав.
