# ADR-017 — Непрерывный редактор Lexical на листах A4

**Статус:** реализация клиентской части фазы 4.

Студент открывает редактор из кабинета. Lexical 0.53 редактирует один
`contenteditable`. CSS Multi-column Layout разбивает этот поток на колонки по
печатной области A4 от сохранённого шаблона. В браузере колонки расположены
горизонтально с переходами к предыдущему и следующему листу, номерами и
масштабом. Измерение переполнения определяет количество листов. Разметка
страниц не сериализуется. Размер листа, поля, отступы и стили берутся из
активной версии шаблона.

Сохранение проецирует JSON Lexical в серверную schema v4. Неизменившиеся
блоки сохраняют исходные поля, включая NodeState главы. Внешний буфер обмена
вставляется обычным текстом. Изображение вставляется по UUID из API загрузки.

Клиент получает аренду при открытии редактора, периодически продлевает её и
освобождает при уходе со страницы. Дебаунс автосохранения — 650 мс. Черновик
хранится в браузере по пользователю и документу до успешной записи. После
конфликта редакция с сервера загружается отдельно. Пользователь может скачать
черновик или явно восстановить его поверх актуального рабочего текста. В
истории доступны отдельные снимки и восстановление с созданием новой версии.

Проверки фазы покрывают перенос строк длинного абзаца и удаление фрагмента
через несколько листов, undo, загрузку и вставку изображения, таблицу,
хранение локального черновика и конфликт двух вкладок. Разбиение сложных таблиц
и сценарии IME в других браузерах остаются предметом приёмки редактора.
