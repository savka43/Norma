# ADR-002 — Тестовое API «Антиплагиат» для проверки workflow

**Статус:** принято пользователем. **Дата:** 2026-11-15.

## Контекст

ЛР1 (с. 3–5, 7) содержит прецедент проверки на антиплагиат; ЛР2
(с. 6, 9) содержит класс `ПроверкаАнтиплагиат` и связь с версией работы.
Пользователь получил согласование использовать тестовое API с ограниченной базой
для демонстрации **работающей интеграции**, а не научной оценки оригинальности.

## Решение

Использовать официальное SOAP/WSDL API:
`https://api.antiplagiat.ru:4959/apiCorp/testapi?wsdl`
(источник: https://docs.antiplagiat.ru/ru/api/).

- Реализовать `plagiarism/client.py` (SOAP-адаптер), `service.py` (оркестрация),
  `crud.py` (история проверок), `views.py` (HTTP статусы и команды).
- Отправлять на проверку **зафиксированную версию** (файл допустимого формата,
  сформированный из редактора); не отправлять незаписанный текущий текст.
- Сохранить статус, внешний ID, дату, доступные проценты и отчёты.
- Внешнюю проверку проводить асинхронно, с долговечным заданием и worker,
  чтобы результат стал доступен и после закрытия браузера.
- После ошибки не делать автоматической повторной загрузки/проверки;
  дать ручную повторную попытку. Отображать фазы и ошибки.
- Внешнему API передавать валидный `ExternalUserId` (не длиннее 40 символов).
- Конфигурация подключения — через защищённые настройки; **не** хранить
  публичные тестовые логин/пароль в репозитории или коде.
- Общий тестовый аккаунт не использовать для настоящих ВКР или персональных данных.

## Не является целью

Точная оценка по полной коммерческой базе, локальный алгоритм антиплагиата,
создание собственной поисковой коллекции. Ограниченная тестовая база достаточна
для учебной демонстрации проверки и пользовательского процесса.

## Источник

https://docs.antiplagiat.ru/ru/api/ — проверен 15.11.2026.
Документация требует асинхронности, отображения фаз, корректной обработки ошибок,
работы с доступными отчётами и внешним идентификатором пользователя.
