# NORMA / пакет для Codex

Скопировать папку в `docs/design/` проекта (или её содержимое в существующую папку дизайна). Порядок чтения: `NORMA_STUDENT_UI_SPEC.md` → `DESIGN_SYSTEM.md` → `COMPONENTS.md` → `tokens.css` → `preview.html`.

Функциональная спецификация обязательна по содержанию, иерархии и сценариям, не по пикселям. Дизайн-система задаёт визуальные ограничения. HTML — самостоятельный демонстрационный каталог, не production и не рабочий редактор; все записи условные. Шрифт IBM Plex Sans подключён через Google Fonts, при отсутствии сети используется fallback; font-файлы в архив не включены. Проверить шрифт в реальном приложении.

## Промпт Codex
Изучи AGENTS.md, действующие требования, архитектуру редактора и текущие UI-компоненты. Прочитай файлы docs/design. Составь соответствие существующих компонентов утверждённой функциональной спецификации. Сохрани бизнес-логику и работающие API, реализуй согласованную компоновку и визуальные правила с React/TypeScript, CSS Modules, TanStack Form. Переиспользуй компоненты, сопоставь токены с существующими. Не копируй внешний вид референсов и не переноси HTML-каталог буквально. Не добавляй Tailwind/shadcn/Tiptap. Не создавай фиктивные серверные операции. Если есть конфликт требований, обозначь его до изменения. Проверь типы, линтер, тесты, визуальные сценарии и клавиатуру; сообщи, что не реализовано. Горячие клавиши, набор иконок, мобильные пороги и API-поля требуют проверки. Остальные роли пока вне этой спецификации.
