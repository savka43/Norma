# Каталог компонентов и критерии реализации

Названия рекомендательные; использовать существующую архитектуру. Все компоненты получают данные через props/существующий state, не хардкодить демонстрационные данные. CSS Modules, React/TS; формы TanStack Form. Без Tailwind, shadcn/ui, Tiptap.

| Компонент | Обязательное содержание и визуальное поведение |
|---|---|
| Button | Primary синий, Secondary белый с границей, Accent зелёный, Ghost текст, Danger красный. Высота 36px обычно, padding 16px. Default/hover/pressed/focus/disabled/loading; без скачка ширины. |
| IconButton | Квадрат 28/32/36px, функциональная иконка, tooltip и aria-label, selected state. |
| Input / SearchInput / Textarea | Белый прямоугольник, 1px border, 36px, padding 12px. Label над полем (для поиска допустим доступный label), placeholder, focus, error, disabled. Поиск с иконкой по необходимости, никогда не скруглять. |
| Select / Dropdown / Menu | Прямоугольный триггер и список, активный пункт светло-синий, клавиатура, Escape, закрытие вне меню. |
| Checkbox / Radio | Нативная семантика, клавиатура, label, checked/focus/disabled. Не добавлять декоративные скруглённые оболочки. |
| Tabs | Нижняя линия 2px, активный синий текст; не использовать капсулы. |
| StudentHeader | Тёмно-синяя шапка, название, четыре текстовых раздела, уведомления, профиль; активный фон и зелёная линия. |
| StatusLabel | 24px, 12/16, белый текст, насыщенный фон по токенам, ширина max-content, без иконок и обрезания. |
| Table | Нейтральная шапка, горизонтальные разделители, белые строки, без вертикальных линий и zebra по умолчанию. Даты и количества выровнены последовательно. |
| Dialog | Заголовок, содержимое, действия внизу справа, фокус внутри, закрытие Escape если безопасно. Без декоративной иллюстрации. |
| Toast / InlineError / Skeleton / EmptyState | Белая поверхность, текст, функциональная граница/акцент. Ошибка локальна, повтор при возможности. Skeleton без изменения размеров контента. |
| ThesisSummary / StageIndicator | Тема, руководитель, линейные сегменты 4px, подписи, текущий этап. Без кнопки редактора и процентов. |
| RecentRemarksList / DeadlineList | Простые строки, раздел, текст, переход к фрагменту, фактические сроки. |
| MaterialRow / MaterialSearch / MaterialPreview | Текстовый формат PDF/DOCX, название, размер, просмотр и скачивание. Поиск и категории. PDF viewer с независимой прокруткой. |
| DocumentHeader | Назад, название, реальный статус сохранения, белый экспорт, зелёная отправка. |
| EditorMenuBar / FormattingToolbar / ModeSelector | Меню и компактные инструменты. Режим справа, подсказки шорткатов; не добавлять отдельную постоянную строку режимов. |
| DocumentOutline | Дерево заголовков, выбранный раздел, навигация, сворачивание. |
| DocumentViewport / DocumentPage | Страницы А4, скролл, масштаб; не подменять существующий editor textarea. |
| WorkspaceToolRail / AuxiliaryPanel | 32px рейка, одна панель 264px, resize 240–480, закрытие, независимый скролл. Правки, материалы, история, оформление. |
| CommentThread | Автор, дата, глава/страница, текст, ответы, исправлено/ожидает подтверждения. Выбранная строка с нейтральным фоном и левой границей. |
| TextSuggestion | Исходный и новый фрагменты, подписи, красный/зелёный фон, тёмный текст без зачёркивания, принять/отклонить/обсудить, конфликт. |
| DiffViewer | Две версии рядом или совмещённо, версии/даты, переходы по изменениям, подсветка отключается, только чтение. Без зачёркивания. |
| EditorStatusBar | Страница, слова, профиль оформления, масштаб; достоверные значения. |
| AuthForm | Вход в центральной белой форме на светлом фоне с синей шапкой. Регистрация без выбора привилегированной роли. |
| ProfileMenu / ProfilePage | Меню из шапки; вкладки личные данные, безопасность, уведомления. Поля сверить с API. |
| NotificationPopover | Счётчик, фильтр, прочитать все, событие/дата/переход. Непрочитанное — сплошной светло-синий фон и левая граница. |

## Проверка качества
- Статусы и названия не обрезаются, длинные комментарии переносятся. Поля поиска и все контролы без скруглений.
- Проверить keyboard focus, порядок Tab, меню и диалоги, обработку ошибок и отсутствие фиктивного успеха.
- В редакторе проверять независимый скролл, resize, переключение режимов с сохранением черновика, привязку замечаний, принятие/отклонение/конфликт, отсутствие зачёркивания, материалы без выхода.
- Проверить реальные страницы на широком и узком desktop; не фиксировать размер текста через SVG. Не переносить демонстрационный HTML в production вместо React-компонентов.
