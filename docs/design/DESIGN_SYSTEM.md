# Норма — дизайн-система v0.1

Согласовано 27.11.2026 для студенческой части. Функциональная спецификация отвечает за состав, иерархию и поведение, этот документ — за визуальные правила. HTML-каталог иллюстрирует их, а не задаёт пиксельный эталон. Остальные роли используют эти же основы, но их страницы ещё не проектировались.

## 1. Визуальное направление
Светлый строгий рабочий интерфейс, сине-зелёная идентичность. Никаких скруглений (включая поиск, select, модальные окна), градиентов, полупрозрачных цветных поверхностей, стекла, декоративных иконок, лишних карточек, больших баннеров. Тени допустимы только для отделения всплывающего слоя, если необходимы. Linear, Google Docs, JetBrains, GitHub — функциональные референсы, не визуальные шаблоны. Не копировать их компоненты или бренд.

## 2. Цвета
Источник точных значений — tokens.css. Шапка обоих layout: #102F42; активная навигация #16455F с нижней зелёной полосой #69A05B. Основное действие #165373, подтверждение #395D30. Фон #F5F7F7, рабочие поверхности белые, текст #20282D, вторичный #66737A. Исходный #68757C давал контраст 4,41:1 на фоне #F5F7F7; текстовый токен затемнён после проверки. Цвет фона нейтрального статуса остаётся #68757C. Границы 1px #DCE2E4; у контролов #C4CDD1. На тёмной шапке экспорт белый с тёмно-синим текстом, отправка на проверку зелёная с белым текстом. Цвет не должен быть единственным носителем значения.

Статусы: белый текст 12/16 на насыщенном непрозрачном фоне: не отправлено #68757C, на проверке #165373, нужны правки #986323, проверено успешно #395D30, отклонено #A43D3D (только там, где доменная модель поддерживает). Без иконок, рамок, скругления и теней. Не обрезать текст, ширина по содержимому, высота 24px, padding 0 8px, nowrap. На узком экране менять таблицу или дать горизонтальный скролл, не сжимать метку.

## 4. Геометрия
Шаг 4px; 4/8/12/16/20/24/32/40/48. Контент кабинета max 1200px, внешние отступы 32px, секции 32px, блоки 20px. Шапка 56px. Контролы 28 (инструменты), 32 (малые), 36 (стандарт), 40 (формы при необходимости). Строка таблицы ориентир 44px, растёт при длинном содержимом. Редактор: toolbar 40px, структура 240px (может быть компактнее), правая панель 264px с регулировкой 240–480px, рейка 32px, строка состояния 28px. Панель не перекрывает документ на широком экране; если места мало, скрывать панели или прокручивать рабочую область, не искажать страницы. Пороговые значения адаптивности не утверждены.

## 5. Иконки
Конкретная библиотека не выбрана. Использовать уже имеющуюся согласованную библиотеку, либо предложить одну до добавления зависимости. Единообразная функциональная иконография: 16px в toolbar и кнопках, 16px в правой рейке, 20px в навигационных действиях. Текстовые названия разделов без иконок; статусы без иконок. Tooltip и accessible name для кнопок без текста. Не смешивать разные наборы ради декора.

## 6. Редактор
Белые страницы на #E5E9EB, белые вспомогательные панели, toolbar #F5F7F7. Активная строка структуры #EAF2F6 с синей левой границей. Активная кнопка рейки #D7E5ED. Комментарий #F1E6C7. Исходный/удалённый текст #F5E4E4 с красной границей, новый #E2EDD9 с зелёной. Текст остаётся тёмным, без зачёркивания в любом режиме. Явные подписи исходного и нового текста; возможность скрывать выделение. Не включать эти цвета в экспортируемый документ. Панели прокручиваются независимо, правки и материалы доступны без выхода из workspace.

## 7. Доступность и состояния
Сохранять видимый keyboard focus, клавиатурную навигацию, семантические элементы, подписи полей и ошибки под ними. Hover — изменение сплошного цвета, без прыжков и масштабирования. Проверить контраст и читаемость фактического шрифта (особенно вторичный текст, границы полей, disabled); при необходимости скорректировать токены минимально и задокументировать. Не объявлять демонстрационные результаты реальными. Загрузка сохраняет геометрию, ошибка имеет действие повторить, пустые состояния объясняют дальнейший шаг. Не утверждены логотип Нормы, точная библиотека иконок и mobile breakpoints.
