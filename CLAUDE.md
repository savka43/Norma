# Инструкции для Claude Code

Общие правила всех агентов находятся в [AGENTS.md](AGENTS.md). Прочитай их перед задачей.
Единственный действующий план разработки — [docs/plans/roadmap.md](docs/plans/roadmap.md).
Требования, архитектура и ADR — только связанные с ним актуальные документы `docs/`.

Не составляй отдельный план продукта по старым инструкциям Claude и не используй
`docs/archive/` как источник требований. Прежний контекст сохранён в
`docs/archive/claude/context-legacy.md` только для истории.

Frontend-навыки доступны в `.claude/skills/`; правила их применения и ограничения
стека указаны в `AGENTS.md`.
